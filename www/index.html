Un co-científico en tu terminal. Le cuentas con tus palabras lo que quieres averiguar y trabaja contigo: propone el camino, comprueba lo que hace falta, enseña cada comando antes de ejecutarlo y deja constancia de lo que hizo para que otra persona pueda comprobarlo.

A co-scientist in your terminal. Tell it in your own words what you want to find out and it works alongside you: it proposes the route, checks what is needed, shows every command before running it, and leaves a record of what it did so that someone else can check it.

Copy this line, paste it and press Enter

$ curl -fsSL https://webiwabou.github.io/bioinformatica.org/install | bash
> irm https://webiwabou.github.io/bioinformatica.org/install.ps1 | iex

Tarda menos de un minuto. Descarga el programa que corresponde a tu sistema, lo deja en ~/.bioinformatica/bin y añade esa carpeta a tu PATH. No pide contraseña ni permisos de administrador: vive en tu carpeta personal.

It takes less than a minute. It downloads the build for your system, puts it in ~/.bioinformatica/bin and adds that folder to your PATH. No password and no administrator rights: it lives in your home folder.

En Windows hay un paso más, y el instalador se encarga. Las herramientas que el agente orquesta necesitan Linux, y Windows ya lo trae: se llama WSL. Si no lo tienes, el instalador te enseña el comando que lo instala y te pide permiso antes de nada. Eso sí pide permisos de administrador y reiniciar una vez. Después el agente vive dentro de ese Linux y tú lo llamas desde PowerShell como cualquier otro programa.

Windows has one extra step, and the installer handles it. The tools the agent drives need Linux, and Windows already ships it: it is called WSL. If you do not have it, the installer shows you the command that installs it and asks before doing anything. That part does need administrator rights and one restart. After that the agent lives inside that Linux and you call it from PowerShell like any other program.

Pegar un comando que no has leído es un acto de confianza. Puedes leer antes lo que hace: el de macOS y Linux, el de Windows.

Pasting a command you have not read is an act of trust. You can read it first: the macOS and Linux one, the Windows one.

Hay que reabrirla para que reconozca el comando nuevo. Después, conecta un proveedor de modelos y entra en la carpeta de tu trabajo:

You need to reopen it for the new command to be recognised. Then connect a model provider and go into your working folder: 

$ bioinformatica providers login   # conectar un proveedor
$ cd ~/mi-analisis                 # tu carpeta de trabajo
$ bioinformatica                   # abrir la interfaz
$ bioinformatica providers login   # connect a provider
$ cd ~/my-analysis                 # your working folder
$ bioinformatica                   # open the interface

Qué más necesita el ordenadorWhat else the computer needs

El agente orquesta herramientas del ecosistema y no las sustituye. Para ejecutar análisis de verdad hacen falta Nextflow con un Java compatible, y un backend de contenedores: Docker, o conda/mamba.

The agent drives the tools of the ecosystem, it does not replace them. To run real analyses you need Nextflow with a compatible Java, and a container backend: Docker, or conda/mamba.

No hace falta instalarlos antes. Este comando inspecciona el ordenador y dice, para cada pieza que falte, si se puede instalar sin permisos de administrador y el comando exacto. Es de sólo lectura: recomienda, nunca instala.

You do not need to install them first. This command inspects the machine and reports, for every missing piece, whether it can be installed without administrator rights and the exact command. It is read only: it recommends, it never installs. 

$ bioinformatica debug env
Comprobar lo que has descargadoChecking what you downloaded

Cada versión publicada lleva un fichero SHA256SUMS junto a los programas. Si te descargas uno a mano desde las releases, puedes comprobar que es exactamente el que se publicó:

Every published version ships a SHA256SUMS file next to the builds. If you download one by hand from the releases, you can check that it is exactly the one that was published: 

$ sha256sum --check SHA256SUMS

Por qué existeWhy it exists

Un resultado producido por un agente tiene que poder defenderse ante alguien que no estuvo en la sala: un director de tesis, un revisor, uno mismo dieciocho meses después. Y ahí el relato del propio agente no vale nada. Por eso, sobre cada campaña, Bioinformática.org emite cuatro artefactos pensados para que los verifique un tercero sin ejecutar el agente, sin modelo y sin red, y para que digan en voz alta lo que no demuestran.

A result produced by an agent has to stand up in front of someone who was not in the room: a thesis supervisor, a reviewer, yourself eighteen months later. And there the agent's own account of itself is worth nothing. That is why, for every campaign, Bioinformática.org emits four artefacts built to be verified by a third party without running the agent, without a model and without a network, and to say out loud what they do not prove.
