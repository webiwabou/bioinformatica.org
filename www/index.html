Instálalo con una línea en la terminal

Bioinformática.org es un agente de terminal: le describes tu pregunta biológica con tus palabras y él busca el pipeline de nf-core, comprueba la máquina, construye el comando de Nextflow, te lo enseña y pide tu aprobación antes de ejecutar nada.

1

Abre la terminal

macOS Pulsa ⌘ + Espacio, escribe Terminal y pulsa Enter.
Linux Pulsa Ctrl + Alt + T, o busca Terminal entre tus aplicaciones.
Windows Abre PowerShell como administrador, ejecuta wsl --install y luego abre Ubuntu. Nextflow necesita Linux.
2

Copia esta línea, pégala y pulsa Enter

$ curl -fsSL https://webiwabou.github.io/bioinformatica.org/install | bash

Tarda menos de un minuto. Descarga el binario que corresponde a tu sistema desde las releases de GitHub, lo deja en ~/.bioinformatica/bin y añade esa carpeta a tu PATH. No pide contraseña ni permisos de administrador, y no toca nada fuera de tu carpeta personal.

Pegar un comando que no has leído es un acto de confianza. Puedes leer el script antes de ejecutarlo: es bash, hace exactamente lo que dice el párrafo de arriba y nada más.

3

Cierra la terminal, ábrela de nuevo y arranca

Hay que reabrirla para que tome el PATH nuevo. Después, conecta un proveedor de modelos y entra en la carpeta de tu análisis: 

$ bioinformatica providers login   # conectar un proveedor de modelos
$ cd ~/mi-analisis                 # tu carpeta de trabajo
$ bioinformatica                   # abrir la interfaz

No trae modelo propio: funciona con Anthropic, OpenAI, Gemini, DeepSeek, Qwen, OpenRouter o un modelo que sirvas tú en local con Ollama o vLLM. Las recetas concretas están en docs/modelos.md.

Y ya puedes escribirle en tus propias palabras:

> Tengo 12 FASTQ pareados de RNA-seq de hígado de ratón en ./datos,
> seis controles y seis tratados. Quiero cuantificar expresión génica.

Qué más necesita la máquina

El agente orquesta herramientas del ecosistema; no las sustituye. Para ejecutar pipelines de verdad hacen falta:

  • Nextflow y un Java compatible
  • un backend de contenedores: Docker (preferido) o conda/mamba
  • opcionalmente nf-core tools, para lint y contribución

No hace falta que los instales antes. Una vez instalado el agente, este comando inspecciona la máquina y te dice, para cada pieza que falte, si se puede instalar sin root y el comando exacto. Es de sólo lectura: recomienda, nunca instala. 

$ bioinformatica debug env

Comprobar lo que has descargado

Cada release lleva un fichero SHA256SUMS junto a los binarios. Si te descargas uno a mano desde la página de releases, puedes comprobar que es exactamente el que se publicó: 

$ sha256sum --check SHA256SUMS

Otras formas de instalarlo

  • Una versión concreta: curl -fsSL https://webiwabou.github.io/bioinformatica.org/install | bash -s -- --version 0.1.0
  • El binario suelto, sin script: descárgalo de releases y ponlo en tu PATH.
  • Desde el código fuente, con Bun 1.3.x: las instrucciones están en el README.

Por qué existe

Un resultado producido por un agente tiene que poder defenderse ante alguien que no estuvo en la sala: un director de tesis, un revisor, uno mismo dieciocho meses después. Y ahí el relato del propio agente no vale nada. Por eso, sobre cada campaña, Bioinformática.org emite cuatro artefactos diseñados para que los verifique un tercero sin ejecutar el agente, sin modelo y sin red — y para que digan en voz alta lo que no demuestran.
